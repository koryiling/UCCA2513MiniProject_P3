Section labels and purpose

  1. 1Header / navigation bar – Logo (top-left), site name, menu (Home, Admission, Application, FAQ) and Login button (top-right). Same on every page.
  2. 2Hero banner – Short welcome message; buttons lead to admission information or open the chatbot.
  3. 3Upcoming deadlines strip – Preview from Application Date & Reminder.
  4. 4Main content – The two original core areas: Admission Requirements and Application Procedure.
  5. 5Admission Tools (modules) – Six module cards in two groups that match the menu. A dashed slot is reserved for modules added later.
  6. 6Chatbot panel – Rule-based assistant with suggested questions and links to modules.
  7. 7Footer – Official UTAR link, Contact Us, FAQ, social icons.
  8. 8Module input area – Every module page uses the same layout: breadcrumb, title, input on the left.
  9. 9Result area – Output on the right, with a disclaimer and an official source link. Alternative pathways appear here if a requirement is not met.
  10. 10Floating chat button – Bottom-right on module pages; opens the same chatbot.
  11. 11Journey Tracker – Stages updated by the student (login required).
  12. 12Document Checklist – Saved checklist generated by the module (login required).
  13. 13Dates & Reminders – Upcoming deadlines highlighted on the dashboard.
Login (proposed, confirm with group) Guests can use the chatbot, Explainer, Eligibility Checker, Pathways and Dates. Login is needed only to save the checklist, the tracker and personal reminders.
Technology stack Frontend: HTML, CSS, JavaScript · Backend: Node.js · Database: MySQL · Design: Figma
