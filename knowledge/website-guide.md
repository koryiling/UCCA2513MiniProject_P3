# Website Guide: pages and tools

This website (UTAR Admission Assistant) has these pages. Link to them by file name, e.g. [Application page](application.html).

## Pages
- Home (index.html): overview of the whole site, key facts and quick links.
- Admission (admission.html): accepted qualifications, English-language requirement, programme-specific notes, and the admission tools.
- Application (application.html): the 6 application steps, upcoming intakes, documents to prepare, and the application tools. Students must log in (or sign up) to open this page.
- Tuition Fees (fees.html): fee overview by study level.
- Scholarship Information (scholarship.html): scholarships, financial aid and how to apply.
- Student Life (student-life.html): campus (Kampar and Sungai Long), faculty and facilities. Sections: student-life.html#campus, student-life.html#faculty, student-life.html#facilities.
- FAQ (faq.html): short answers to common questions.
- Login (login.html) and Sign Up (signup.html): needed only for the Application section.

## The six tools (modules)
Admission tools, on the Admission page (admission.html#tools), open to everyone:
1. Admission Requirement Explainer: explains a programme's requirements in simple language.
2. Smart Eligibility Checker: the student enters their qualification and results and gets an indicative (not official) eligibility result.
3. Alternative Pathway Recommendation: suggests other routes, such as foundation or diploma programmes, when a requirement is not met.

Application tools, on the Application page (application.html#tools), login required:
4. Personalized Document Checklist: a list of supporting documents for the student's situation, which they can tick off and save.
5. Application Journey Tracker: shows the application stages (explore programme, check eligibility, prepare documents, submit application, await offer); the student updates their own progress. It is not connected to UTAR's official system.
6. Application Date & Reminder: important intake dates and reminders of upcoming deadlines.

The tool pages are still being built. Until they are ready, help the student directly in the chat using the knowledge base (for example, explain requirements or list documents), and mention which tool and page will help them.
